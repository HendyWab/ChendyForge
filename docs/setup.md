# Local Development Setup

## Requirements

- Node.js 22+
- npm 10+
- Git

---

## Clone Repository

git clone https://github.com/HendyWab/ChendyForge.git

cd ChendyForge-app

---

## Install Dependencies

npm install

---

## Start Development Server

npm run dev

---

## Build Production

npm run build

---

## Lint

npm run lint
