# Contributing to ChendyForge

Thank you for contributing.

---

## Workflow

1. Create issue
2. Assign issue
3. Create feature branch
4. Open Pull Request
5. Review
6. Squash Merge

---

## Branch Naming

feature/issue-modal

feature/persist-board

feature/websocket-gateway

fix/board-scroll

docs/architecture

---

## Commit Convention

feat: add issue modal

fix: resolve board persistence

docs: update architecture

refactor: cleanup zustand store

style: improve board cards

---

## Pull Requests

Every PR must:

- Reference an Issue
- Pass Build
- Pass Lint
- Be Squash Merged

---

## Code Style

- TypeScript
- Functional Components
- TailwindCSS
- Feature Based Architecture
